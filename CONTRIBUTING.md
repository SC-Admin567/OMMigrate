# Contributing to OMMigrate

Thanks for your interest in OutlookMailMigrator (OMMigrate)!

---

## Bug Reports and Questions

**These are very welcome -- please open an Issue.**

To help diagnose your issue quickly, please include:

- Windows version (Settings -> System -> About)
- Outlook version (Outlook -> File -> Office Account)
- PowerShell version (run `$PSVersionTable.PSVersion`)
- The account type(s) involved (POP3, IMAP, Exchange, AT&T/Yahoo legacy,
  AWS SES, etc.)
- Which script the issue occurred in (00-04) and the exact error message
- Relevant excerpts from `Documents\OutlookMigration\Logs\` for that run
- Whether the issue is reproducible on re-run

The more detail you provide up front, the faster this can be tracked down.

---

## Pull Requests

**OMMigrate is not currently accepting code contributions.**

This is a solo project in its early public phase. Before opening the
codebase to outside changes, I want to build up real-world testing
experience across the range of Windows/Outlook environments and account
types this tool needs to handle correctly.

This will change in the future. If you have an idea for a fix or a new
feature in the meantime, please open an Issue to discuss it -- I read
every one, and your input helps shape what gets prioritized even though
I can't merge external PRs yet.
